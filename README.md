# Weather App 🌤️

A simple weather application built using **React.js** that shows the current weather information of a city.

## 🚀 Live Demo

[Weather App](https://weatherappfor.vercel.app/)

## 🛠️ Technologies Used

* React.js
* Vite
* JavaScript
* Material UI
* OpenWeather API

## ✨ Features

* Search weather by city name
* Shows temperature
* Shows humidity
* Shows minimum and maximum temperature
* Shows weather condition
* Responsive UI

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/nishant1800/Weather-App.git
```

Go to the project folder:

```bash
cd Weather-App
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

## 🌐 Deployment

The project is hosted on **Vercel**.
